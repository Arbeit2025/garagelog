# うちのガレージ記録（garagelog）

車・バイクの給油／整備／車検・点検などを1か所に記録する小さな Web ツールです。

## 使い方

- **記録の追加**：日付・車両名・区分（給油／整備／車検・点検／その他）を必須として、走行距離(km)・給油量(L)・金額(円)・メモ・期限を任意で記録できます。
- **燃費の自動計算**：同じ車両の給油記録が2件以上あると、前回給油からの走行距離 ÷ 今回の給油量で燃費（km/L）を計算し、一覧の行に表示します。
- **期限が近いもの**：期限（due date）を設定した記録を期限の早い順に一覧します。過ぎたものは「期限切れ」と強調表示されます。車検や保険、オイル交換の目安に。
- 記録は1件ずつ削除できます（確認ダイアログ付き）。

データは SQLite に保存されます。DB のパスは環境変数 `GARAGELOG_DB` で変更できます。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- 燃費は「満タン法」前提の単純計算です。前回給油に走行距離がない場合や、距離が増えていない場合は計算されません。
- 期限の通知機能はありません。一覧で目視確認するだけです。
- ログイン機能はありません。Render 無料プランでは SQLite のデータが再デプロイ等で消える場合があります。
